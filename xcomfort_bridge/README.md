# Home Assistant App: xComfort MQTT Bridge

![Local](https://img.shields.io/badge/100%25-local-12a150) ![No cloud](https://img.shields.io/badge/cloud-not%20needed-7c3aed)

Control your **Eaton / Sensio xComfort** installation from Home Assistant, **without** the eoptHome app or
Eaton's cloud.

The app talks directly to the xComfort **Home Manager** on your local network and brings lights, switches, wall
buttons, awnings, thermostats and sensors into Home Assistant through MQTT. Changes from a wall switch show up in
under a second.

With the optional xComfort USB stick **CKOZ-00/13**, lights are controlled directly over radio and react
instantly, with the Home Manager as fallback.

**Getting started:** fill in the Home Manager IP and an MQTT user on the Configuration tab, start the app and
open **xComfort** in the sidebar. A guide takes you through the rest.

See the Documentation tab for more details.
