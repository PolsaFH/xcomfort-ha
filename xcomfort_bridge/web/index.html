Using the buttons in automations

Each button is an event entity in Home Assistant. Create an automation with the Event received trigger on the button and choose the type of press:

short_up
short press up
short_down
short press down
long_up
holding up
long_up_release
released after holding up
long_down
holding down
long_down_release
released after holding down

1. Search the Home Manager

The app goes through everything in the Home Manager and finds dimmable lights, on/off switches, awnings, thermostats, sensors and buttons. It takes 10 to 20 minutes and does not affect the radio, so you can close the page meanwhile. Run it again after changes in MRF or xSetup.

2. Choose what goes into Home Assistant

Give each device a name and a room. Each room becomes a device in Home Assistant, so everything ends up neatly sorted. You can change the name and room later with the pencil under Rooms.

USB stick optional

Plug the xComfort stick CKOZ-00/13 (the one MRF uses) into the machine that runs Home Assistant. Light commands are then sent straight out over radio, and the lights react instantly. If a dimmer does not answer, the Home Manager takes over automatically.

USB map which dimmers each light controls

The stick needs the radio serial numbers of the dimmers behind each light. The app can find them itself: it sends a command through the Home Manager to one light at a time and listens for which dimmers receive it. The lights do not visibly change. Takes about 10 seconds per light.
